# Curated Results

This directory intentionally contains no final benchmark result yet.

Generated run artifacts belong under `artifacts/runs/<run-id>/` and remain
ignored by Git. `results/pilot/` contains small, reproducible scheduler-calibration
and comparative-pilot summaries, tables, and diagnostic figures regenerated from
canonical run manifests and trial summaries. Every pilot figure is labeled
`PILOT / DIAGNOSTIC — NOT FINAL BENCHMARK`; these files are not performance claims.
